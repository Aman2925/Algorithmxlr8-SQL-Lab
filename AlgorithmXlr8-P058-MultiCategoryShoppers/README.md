# Multi Category Shoppers

**Level:** `Level 3` · **Topic:** `Aggregation`

## Problem

The `Orders` table stores the category and amount of every order.

Find the customers who bought from at least 3 different categories and whose biggest category makes up less than 50 percent of their total spend.

Return `customer_id`, sorted from smallest to largest.
