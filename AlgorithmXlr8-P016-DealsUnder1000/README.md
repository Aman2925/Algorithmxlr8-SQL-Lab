# Deals under 1000

**Level:** `Level 2` · **Topic:** `Select and Filter`

## Problem

The `Products` table stores each product's price and its discount in percent. A NULL discount means no discount.

The final price is the price after the discount. Find the products whose final price is below 1000. Round the final price to 2 decimal places.

Return `product_id`, `name` and `final_price`, sorted by final_price and then by product_id.

## Tables

### Products

| Column | Type |
| --- | --- |
| product_id | int |
| name | varchar |
| price | int |
| discount_pct | int |
