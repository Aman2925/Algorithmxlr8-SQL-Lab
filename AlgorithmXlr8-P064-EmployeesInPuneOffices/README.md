**Level:** `Level 1` · **Topic:** `Subqueries`

## Problem

The `Offices` table stores the city of each office and the `Employees` table stores the office of each employee. A city can have more than one office.

Find the employees who work in an office in Pune.

Return `name`, sorted alphabetically.
