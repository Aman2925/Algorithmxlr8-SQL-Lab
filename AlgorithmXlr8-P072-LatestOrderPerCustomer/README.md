# Latest Order per Customer

**Level:** `Level 2` · **Topic:** `Subqueries`

## Problem

The `Orders` table stores each order with the customer and the order date. A customer places at most one order per day.

For each customer, find their most recent order.

Return `customer_id`, `order_id` and `order_date`. The rows can be in any order.
