# Closest to the Budget

**Level:** `Level 3` · **Topic:** `Select and Filter`

## Problem

A customer has a budget of 1000. The `Products` table stores the price of every product.

Find the products whose price is closest to 1000, either above or below it. Report every product tied for the smallest difference.

Return `product_id`, `name` and `price`, sorted by product_id.
