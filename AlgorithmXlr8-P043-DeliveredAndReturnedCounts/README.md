# Delivered and Returned Counts

**Level:** `Level 2` · **Topic:** `Aggregation`

## Problem

The `Orders` table stores the seller and status of every order. `status` is `delivered`, `returned` or `cancelled`.

For each seller, report the number of delivered orders, the number of returned orders and the total number of orders. Show 0 when a seller has none of a status.

Return `seller`, `delivered`, `returned` and `total_orders`, sorted by seller.
