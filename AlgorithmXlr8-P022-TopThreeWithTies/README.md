# Top Three with Ties

**Level:** `Level 3` · **Topic:** `Select and Filter`

## Problem

The `Scores` table stores the score of every student.

Show the top 3 students by score. If the third place is tied, include every student tied with it. If there are fewer than 3 students, show all of them.

Return `name` and `score`, sorted by score from highest to lowest and then by name.
