# Cheap Products in Stock

**Level:** `Level 1` · **Topic:** `Select and Filter`

## Problem

The `Products` table lists every product in a store. `in_stock` is 1 when the product is available and 0 when it is not.

Write a query to find the products that are in stock and cost less than 500.

Return `product_id` and `name`. The rows can be in any order.
