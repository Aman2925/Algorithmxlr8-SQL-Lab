# Customers above Average Spend

**Level:** `Level 2` · **Topic:** `Subqueries`

## Problem

The `Orders` table stores the amount of each order. A customer's total spend is the sum of their orders.

Find the customers whose total spend is above the average total spend of all customers. Note that this is the average of the customer totals, not the average order amount.

Return `customer_id` and `total_spent`, sorted by customer_id.

### Orders
