# Valid Pin Codes

**Level:** `Level 3` · **Topic:** `Select and Filter`

## Problem

The `Addresses` table stores pin codes typed by users.

An Indian pin code is valid when it has exactly 6 digits and does not start with 0. Spaces or any other characters make it invalid.

Return `id` of the addresses with a valid pin code, sorted from smallest to largest.
