**Level:** `Level 3` · **Topic:** `Aggregation`

## Problem

Find the category or categories with the second highest total revenue. If several categories share the highest total, the second highest is the next smaller total. If there is no second highest total, return no rows.

Return `category` and `revenue`, sorted by category.
